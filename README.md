# Rust for C++ Developers - JSI Telecom Online Training

![Ardan Labs](./manual/src/ardanlabs-logo.png)

> **Work in progress.** This is the live-teaching material for the Ardan Labs
> Rust training for JSI Telecom. Chapters that are still being written are
> marked *(placeholder)* below.

## Repository Layout

```text
code/
  Cargo.toml            # workspace; every exNN crate is a member
  ex01_movefail/ ... ex44_oops/
    Cargo.toml
    src/main.rs         # some also have src/bin/ variants
manual/
  book.toml
  src/                  # the book source
  book/                 # generated by `mdbook build`, gitignored
skills/
  rust-design/          # downloadable coding-agent skills (see the Skills chapter)
  anti-slop/
  quality-gates/
  update-readme/
```

## Getting the Code

```bash
git clone https://github.com/thebracket/jsi_oct_2026.git
cd jsi_oct_2026
```

## Viewing the Manual

```bash
cargo install mdbook
cd manual
mdbook serve --open
```

The manual is served at <http://localhost:3000>. To build a static copy instead
(written to `manual/book/`, which is gitignored):

```bash
mdbook build
```

# Introduction

Welcome! This is the Ardan Labs Rust training for JSI Telecom --- delivered remotely over Zoom.

We'll start with your first encounter with Rust, take a whirlwind tour of the language and its ecosystem, then dig into concurrency, async, and traits---before finishing with how to put coding agents to work on Rust code.

The example code lives in the `code/` directory of this repository (examples `ex01_movefail` through `ex45_channels`), and every chapter points at the example that goes with it. Please follow along!
